# Third-party sources

The Python effects pipeline and C++ binding are independently written. Karaoke timing and ruby notation were studied in Aegisub; effects requirements were studied in local PyonFX and karaoke-studio references. No reference-project implementation, Lua scripts or Lua runtime is included.

The C++ text engine uses HarfBuzz for shaping, FreeType for font files and outlines, FriBidi for bidirectional ordering, and Fontconfig for system font matching. Windows wheels bundle native runtime libraries; their notices are in [vendor/runtime-licenses](vendor/runtime-licenses/README.md).

The bundled WGSL translator uses Naga. Notices for its locked Rust dependencies are in [WGSL translator licenses](vendor/runtime-licenses/wgsl/LICENSES.txt).

Tests and visual-validation tools carry unmodified DejaVu Sans regular and oblique
fonts in `tests/fonts/DejaVuSans.ttf` and `tests/fonts/DejaVuSans-Oblique.ttf`, with
their Bitstream/Arev license in `tests/fonts/LICENSE`.
`tests/fonts/KaraTestPrimary.ttf` is a renamed subset of the regular font,
containing only `A` and space plus required layout glyphs. It is distributed
under the same included license and regenerated by `tools/build_test_font.py`
(fontTools is needed only to regenerate it). Its family is `Kara Test Primary`,
and its SHA-256 is
`d307eee89c08c1f977bd305c7ff7c71d6cc7350173827a9c29d710bdc98739c8`.
`tests/fonts/KaraTestHangul.ttf` is a renamed subset of Sarasa UI SC from
`Sarasa-Regular.ttc` (face 7). Its original copyright notices and SIL Open Font
License 1.1 are included in `tests/fonts/LICENSE-Sarasa`. Regenerate it with
`tools/build_hangul_test_font.py`, supplying the original collection and license.
Its SHA-256 is
`8b769bcbdf9c392c0ebdc2a9ca53f082ae41b4bca538e8181ca41f5887ee7ba9`.
The same generator also produces `tests/fonts/KaraTestCJK.ttf`, a renamed subset
containing `時々` for the Japanese iteration-mark regression, under the same
license. Its SHA-256 is
`0739a1972cc3a9caa690f13e94de37065d34b5662df9ddd3d3fd3a90ad4297e2`.
`tests/fonts/KaraTestMultiscript.ttf` is another renamed Sarasa subset for the
fixed Chinese, kana, and Hangul example. It uses the same included SIL Open Font
License and generator as the other Sarasa subsets.
The regular DejaVu Sans fixture SHA-256 is
`6038a160b491e121c1f12c7bccb4a9c8730296e3adc1086a059404ed84b7451c`.
It is included in source distributions for reproducible tests, not in the runtime
Python package. Explicit font registration validates bytes with FreeType and
keeps a private copy for the text engine; rendering applications must load the same
font separately.

Linux source builds use pkg-config and a C++17 toolchain. Windows builds use Meson and MSYS2 UCRT64. See [release builds](docs/contributing/releasing.md).

Hook export uses aggdraw and Pillow. Hook playback uses the host libplacebo installation.

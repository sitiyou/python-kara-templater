# 教程

按步骤带你编写卡拉 OK 模板，从整曲多声部布局一路延伸到高亮触发动效与自定义动画。建议先用包含一个短音和一个长音的短句测试，播放导出的 Hook 确认节奏后再套用到整首歌。

## 按目标选择教程

| 目标 | 教程 | 你会完成什么 |
| --- | --- | --- |
| 排布主唱、注音、和声与倒数提示 | [设计整曲歌词布局](karaoke-design.md) | 包含双行交替、读音与节拍提示的多轨道歌曲模板 |
| 在走字扫到每个字时触发动画 | [为高亮添加自定义动画](lyric-highlights.md) | 随高亮前沿精确触发的逐字跳跃效果 |
| 用 Python 与 GLSL 编写自定义运动曲线 | [编写自定义动画](custom-animation.md) | 让一排旋转火花沿波浪轨迹飞过的可复用工厂 |
| 打造特定的视觉特效 | [特效配方](effect-recipes.md) | 独立配方：无走字提示、狭缝滑出、失焦入场、打字擦除、双态描边与末字碎裂 |
| 在同一句歌词上对比八种动效机制 | [动效对比研究](lyric-studies.md) | 脉冲、重影、粒子、拖尾与独立时钟的横向对比 |

## 推荐学习顺序

1. 先读 [设计整曲歌词布局](karaoke-design.md)，用库内置默认行为搭好声部轨道、双行交替、注音与倒数提示。
2. 需要某种特定视觉处理（例如狭缝显现、无走字跳动标记或唱前唱后双态描边）时，直接查阅 [特效配方](effect-recipes.md)。
3. 如果希望字符或装饰在走字前沿抵达的一瞬间做出反应，跟着 [为高亮添加自定义动画](lyric-highlights.md) 实操。
4. 当内置动画无法满足需求，且你希望自定义曲线能直接导出到 Hook 时，阅读 [编写自定义动画](custom-animation.md)。
5. 最后通过 [动效对比研究](lyric-studies.md) 对比规则、重影、粒子与独立装饰在短音和长音上的组合方式。

> [!TIP]
> 每写一个新模板，都先在 5 秒短片段上验证效果，里面至少包含一个快音节、一个长音和一次换行衔接。先在短片上调准节奏，能省下大量整曲渲染时间。

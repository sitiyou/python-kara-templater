# Contributing

Set up a checkout and run the checks before submitting a change.
[Development setup](setup.md) · [Checks](checks.md)

- To change a feature, use the [architecture guide](architecture.md) to find
  where lyrics, Scene objects, and the two exporters are implemented.
- To change a public interface, update its user guide and regenerate the
  [API reference](checks.md#reference-and-links).
- To update a demonstration, render the exported result and keep the final
  preview in the [effect gallery](../examples/README.md).
- To build and validate distributions, follow the [release guide](releasing.md).
